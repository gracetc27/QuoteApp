# QuoteApp
This project is a simple app that generates random quotes when a button is tapped. 
It makes a network request which returns an array of random quotes and their authors. This call is made any time the uses presses the get quote button. 
The picture background also changes everytime this button is pressed.
This app uses API Ninja's Quote API, so to demo the app, you will need to create an account and enter your own APIKey; their website is under acknowledgments.

# Features
- MVVM architecture
- Unit Tests
- Services for networking
- Use of tasks
- Fun interactive UI
- use of.mask for cool text view
